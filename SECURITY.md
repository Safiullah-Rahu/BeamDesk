# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use GitHub's private [security advisory form](https://github.com/Safiullah-Rahu/BeamDesk/security/advisories/new),
or e-mail the maintainer at the address on the GitHub profile, with:

- a description of the issue and its impact,
- steps to reproduce (a proof of concept if possible),
- the affected version and platform.

You will get an acknowledgement within a few days. We will work with you on a fix and credit you in the release notes (unless you prefer otherwise).

## Supported versions

Security fixes are made for the latest release.

## Design

How BeamDesk protects sessions, and its known limitations, is documented in [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md).
